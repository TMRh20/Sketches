# Sketches

Arduino sketches, small libraries and tools by TMRh20, mostly involving wireless communication with nRF24L01 and nRF52840 radios. More write-ups are on [TMRh20 blog](http://tmrh20.blogspot.com).

> **Note:** This code is proof of concept and may be incomplete. Each folder stands alone and has its own hardware and library requirements.

| Folder | Description |
|--------|-------------|
| [ArduinoQ](ArduinoQ) | RF24 examples and a custom Zephyr firmware build for the Arduino Uno Q |
| [ESP32_WiFiKit32](ESP32_WiFiKit32) | Networked OLED status displays and a DAC audio test for ESP32 boards, from 2020 |
| [MultiWii_Wireless_LCD](MultiWii_Wireless_LCD) | Wireless LCD for checking status and tuning settings on a MultiWii flight controller |
| [NTSC_8Mhz_Example](NTSC_8Mhz_Example) | TV video output from an Arduino Mega, using a USART to shift out pixels |
| [RF24Ethernet](RF24Ethernet) | MQTT over TLS example and a live web map for RF24 mesh networks |
| [RF24Ethernet-lwIP](RF24Ethernet-lwIP) | Experimental lwIP copy of RF24Ethernet, no longer updated here (now in [nRF24/RF24Ethernet](https://github.com/nRF24/RF24Ethernet)) |
| [SPI_UART](SPI_UART) | Library that adds a second SPI bus using a UART, written to drive nRF24L01 modules |
| [TX_0](TX_0) | Wireless audio between AVR Arduinos with nRF24L01 modules, usable as a radio or intercom |
| [XIAO-52840-Sense](XIAO-52840-Sense) | Radio traffic and noise monitor for the XIAO nRF52840 Sense |
| [XIAO-EncryptedAudio](XIAO-EncryptedAudio) | Encrypted wireless microphone and speaker using XIAO nRF52840 Sense boards |
